# ManifoldRack_v1 机柜冷却歧管系统详解

## 一、系统总体架构

这是一个**左供右回**的机柜冷却歧管系统：
- **左侧**：供水歧管系统（Supply Manifold）
- **中间**：服务器支路（Server Branches）
- **右侧**：回水歧管系统（Return Manifold）

系统支持4种运行模式（通过布尔参数组合）：
1. **底进底出**（默认）：`supplyInletAtBottom=true, returnOutletAtBottom=true`
2. **底进顶出**：`supplyInletAtBottom=true, returnOutletAtBottom=false`
3. **顶进底出**：`supplyInletAtBottom=false, returnOutletAtBottom=true`
4. **顶进顶出**：`supplyInletAtBottom=false, returnOutletAtBottom=false`

---

## 二、详细流动路径（以默认"底进底出"模式为例）

### **阶段1：供水入口 → 供水歧管底部**

```
sup_in (机柜边界) 
  ↓
supStubIn (边界连接管，高度提升 dh_sup_in)
  ↓ 
supTee[1].port_1 (第1个三通的底部端口)
```

**关键点**：
- `supStubIn` 实现了从机柜边界到第一个服务器接口高度的**重力势能变化**
- 高度差 `dh_sup_in = z_server[1] - z_bottom`（例如0.09m）
- 这段管道模拟了**静压头损失/增益**

---

### **阶段2：供水歧管的竖向分配**

供水在竖向歧管中**逐级向上分配**，每一级都分出一路去服务器：

```
第1层：supTee[1]
  ├─ port_1 ← 来自入口
  ├─ port_3 → 分出到 Server[1]
  └─ port_2 → supRiser[1] (向上流动，高度差 dz[1])
               ↓
第2层：supTee[2]  
  ├─ port_1 ← 来自 supRiser[1]
  ├─ port_3 → 分出到 Server[2]
  └─ port_2 → supRiser[2] (向上流动，高度差 dz[2])
               ↓
...
               ↓
第n层：supTee[nServers]
  ├─ port_1 ← 来自 supRiser[n-1]
  ├─ port_3 → 分出到 Server[n]
  └─ port_2 → supStubCap → supCap (封帽，死端)
```

**关键特性**：
- 每段 `supRiser[i]` 的长度 = `L_riserSeg[i] = max(|dz[i]|, L_min)`
- 高度差 `dz[i] = z_server[i+1] - z_server[i]`（默认每层0.18m）
- **累积静压变化**：越往上的服务器，入口静压越低（重力势能增加）
- `supCap` 封帽提供**零流速边界条件**

---

### **阶段3：水平支路到服务器**

每个服务器的供水支路经过3个部件：

```
supTee[i].port_3 
  ↓
takeoffLoss[i] (抽头局部阻力，ζ=1.5)
  ↓
supDrop[i] (水平支管，长度L_drop=0.30m)
  ↓
branch[i].port_a (服务器入口)
```

**抽头局部阻力的物理意义**：
- 模拟流体从**大管径歧管**突然进入**小管径支管**的涡流损失
- 压降 `Δp = 0.5 × ζ × ρ × (v²/A²) × q²`
- 系数 `ζ=1.5` 是典型的三通分流损失值

---

### **阶段4：服务器内部换热**

```
branch[i] 组件内部：
  - 根据阀门开度 u_valve[i] 调节流量
  - 吸收热负荷 Q[i]（单位：W）
  - 水温升高：Δt = Q/(ṁ × cp)
  - 压降：取决于阀门特性和流量
```

**Branch_Server_v1** 内部通常包含：
- 可调节阀门（压降随开度变化）
- 换热器（恒定热负荷或温控）
- 内部管路阻力

---

### **阶段5：回水支路汇入**

服务器出水通过对称路径进入回水歧管：

```
branch[i].port_b
  ↓
retDrop[i] (水平支管，长度L_drop=0.30m)
  ↓
mergeLoss[i] (汇入局部阻力，ζ=1.5)
  ↓
retTee[i].port_3
```

**汇入局部阻力的物理意义**：
- 模拟小管汇入大管的**动能损失**和**混合损失**
- 两股流体汇合时的**湍流耗散**

---

### **阶段6：回水歧管的竖向汇集**

回水在竖向歧管中**逐级向下汇集**：

```
第n层：retTee[nServers]
  ├─ port_3 ← 来自 Server[n]
  ├─ port_2 → retStubCap → retCap (封帽，顶部死端)
  └─ port_1 ↓ retRiser[n-1] (向下流动，高度差 dz[n-1])
               
第n-1层：retTee[n-1]
  ├─ port_3 ← 来自 Server[n-1]  
  ├─ port_2 ↑ 来自 retTee[n]
  └─ port_1 ↓ retRiser[n-2]
               
...
               ↓
第1层：retTee[1]
  ├─ port_3 ← 来自 Server[1]
  ├─ port_2 ↑ 来自 retRiser[1]
  └─ port_1 → retStubOut (向下到出口)
```

**关键特性**：
- 流量**逐级累加**：最底层流量最大
- **静压恢复**：向下流动时重力势能转化为压力能
- 温度**混合平均**：各层不同温升的水混合

---

### **阶段7：回水出口**

```
retTee[1].port_1
  ↓
retStubOut (边界连接管，高度变化 dh_ret_out)
  ↓
ret_out (机柜边界)
```

**关键点**：
- `dh_ret_out = z_bottom - z_server[1]` （例如-0.09m）
- 这段管道回收**重力势能**，静压升高

---

## 三、物理过程的精细建模

### **1. 高度差效应（High-Fidelity Elevation Modeling）**

代码通过 `height_ab` 参数实现精确的**静压-动压-位压转换**：

```modelica
// 每段竖管都有精确的高度差
supRiser[i]: height_ab = dz[i] = z_server[i+1] - z_server[i]
```

**伯努利方程应用**：
```
p₁/ρg + v₁²/2g + z₁ = p₂/ρg + v₂²/2g + z₂ + h_loss
```

越高的服务器：
- **入口静压越低**（需克服重力做功）
- **流量分配不均**（底层流量大，顶层流量小）
- 这正是数据中心冷却系统的**实际工程问题**

---

### **2. 局部阻力的精细标定**

```modelica
// 抽头损失
takeoffLoss: Δp = 0.5 × 1.5 × ρ × q²/A²

// 汇入损失  
mergeLoss: Δp = 0.5 × 1.5 × ρ × q²/A²
```

**可标定性**：
- 参数 `zeta_takeoff` 和 `zeta_merge` 可通过实验调整
- 不同管径比、不同流速下的局部损失可精确拟合

---

### **3. 边界管的精确作用**

**为什么需要 `supStubIn/Out` 等边界管？**

假设机柜底部在 z=0，第一个服务器在 z=0.09m：
- **没有边界管**：入口直接连接 supTee[1]，高度差被**忽略**
- **有边界管**：`supStubIn` 显式建模 0→0.09m 的静压变化

这在**实际工程**中非常重要：
- 机柜底部管道可能有1-2米高度
- 忽略这段高度会导致**压力计算偏差5-20 kPa**

---

## 四、其他运行模式的流动差异

### **模式2：底进顶出**
```
供水：sup_in → 从底部向上分配
回水：从顶部向下汇集 → 顶部出口
```
**特点**：
- 回水需要**额外泵压克服重力**
- 适合外部回水管路在顶部的场景

---

### **模式3：顶进底出**
```
供水：sup_in → 从顶部向下分配
回水：从底部向上汇集 → 底部出口
```
**特点**：
- 供水利用**重力加速**，顶层压力高
- 可能导致顶层服务器流量**过大**

---

### **模式4：顶进顶出**
```
供水：顶部进 → 向下分配
回水：向上汇集 → 顶部出
```
**特点**：
- **U型流动**，适合顶部母管配置
- 静压分布最复杂

---

## 五、典型数值示例（nServers=10）

假设条件：
- 入口压力：200 kPa
- 入口温度：15°C
- 每台服务器热负荷：500 W
- 总流量：1 kg/s

**流动特征**：

| 服务器 | 高度(m) | 静压损失(kPa) | 流量(kg/s) | 出口温度(°C) |
|--------|---------|---------------|------------|--------------|
| 1      | 0.09    | -0.9          | 0.12       | 16.0         |
| 5      | 0.81    | -7.9          | 0.10       | 16.2         |
| 10     | 1.71    | -16.8         | 0.08       | 16.5         |

**压力梯度效应**：
- 每上升0.18m → 静压降低约1.8 kPa
- 顶层流量比底层少**约30%**（需通过阀门补偿）

---

## 六、工程意义

这个模型可用于：

1. **流量平衡优化**：计算每台服务器的阀门开度，实现均匀冷却
2. **泵扬程设计**：考虑重力+沿程+局部阻力的总压降
3. **温度场预测**：不同负荷分布下的回水温度
4. **故障诊断**：某台服务器流量异常时的系统响应

这是一个**高保真度**的多物理场耦合模型，远超简单的管网计算！
