## Putting hints where practice happens

Flypy double-pinyin represents a syllable with two keystrokes. A beginner needs to remember the mapping and build a habit through continuous typing. The software highlights the keys needed for the current character, bringing guidance into the practice interface.

## Immediate, specific feedback

Built with C++ and Qt, it imports text from files or the clipboard and compares input with the original. Timing, speed, errors, and corrections help learners observe their practice; local settings preserve preferences.

## Shared authorship

This course project was jointly developed with Daining Bao in 2022. The source is public and primarily targets Windows and the Qt desktop environment.
